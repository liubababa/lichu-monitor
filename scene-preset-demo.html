调参

改了什么

1环境贴图。洙边场景在 solar-scene3d.js:1481 用 PMREM 从天空穹顶烘了 IBL，而旭日东明 gaote-scene3d.js 全文 0 处 environment / envMap —— 只有半球光 + 两盏平行光。
这就是"两站不像同一个产品"的技术根因：没有 IBL 的 PBR 材质一定是平、哑、塑料感。

2色调映射。两个场景都没设 renderer.toneMapping， 默认 NoToneMapping → 自发光一旦超过 1.0 就直接裁成纯白 255。 机柜顶圈和电缆流光带现在就是两块纯白。

3夜间没有天空。THEMES.night.sky = null （gaote-scene3d.js:48），白天有渐变穹顶、夜里没有， 所以地面边缘直接淡出进纯黑，地平线消失。

4地面是随机污渍。gaote-scene3d.js:161-168 画了 26 个 4–12px 的随机椭圆（7% 黑），在近景读作水渍/脏斑； :153 的 9000 个 1px 随机点在远距离被 mipmap 平均成噪点。 换成确定性的分块混凝土板 + 板缝 + 逐板明度差。

5缺接触阴影。只有方向光 shadowMap，夜里光照一低 物体就像浮在地上。加一张软边暗斑，零成本、立刻落地。

6浮标没有引线。洙边的标签有引线三角，旭日东明的没有， 标签会跟几何体重叠、看不出指谁。

落地方式

建议抽一个 js/scene-preset.js 导出 window.ScenePreset： 光照参数、天空渐变、地面贴图生成器、接触阴影、自发光上限。
两个场景各自 ScenePreset.apply(renderer, scene, theme)， 旭日的 preset 差异就变成配置而不是两套美术代码。
