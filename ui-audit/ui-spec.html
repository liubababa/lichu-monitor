五、"科技质感"从哪来 —— 该加的和不该加的

现在的问题是把预算花在了装饰上，而工业感真正依赖的几件事一件都没做

停止投入 · 装饰性元素

  1. 斜切页签 — .tab 带 skewX(-14deg)（子元素再反向斜切补偿），平行四边形是游戏 HUD 语言，不是电力 SCADA 语言
  2. 四角括号 — 卡片四角的 L 形亮块，是游戏 HUD 语言，不是电力 SCADA 语言
  3. 渐变裁切标题 — background-clip:text 做标题渐变，白天主题下几乎糊成一片
  4. 全彩霓虹外发光 — box-shadow 0 0 8px 主色 用了 7 处，发光应只属于"活的"数据
  5. 扫描线动画 — scanline keyframes 与 25s/26s 超长过渡，只增加视觉噪声
  6. 页签上的 ▾ 箭头 — 无下拉功能，纯装饰，反而误导可点

开始投入 · 质感来源

  1. 表面层级 — 4 级明度 + 1px 发丝线代替外发光，一眼看出谁在谁之上
  2. 等宽数字 — tabular-nums + 千分位，实时刷新时数值不位移，这是"仪表"感的底线
  3. 数值微图表 — 每个 KPI 带 24h 迷你趋势线（sparkline），空黑区域立刻变成信息
  4. 状态语言统一 — 运行/待机/限功率/故障四态，颜色+图标+文字三重编码，色盲也可读
  5. 数据密度节奏 — 主指标 18px、次级 13px、说明 11px 三档交替，形成扫描节奏
  6. 克制的动效 — 120/180/240ms 三级 + 统一缓动，只用于状态切换与数值过渡
  7. 空态设计 — "暂无数据"要有原因和下一步动作，而不是留一块黑

六、两个电站不像同一个产品

同一套系统内的视觉分裂，比单页不好看更伤专业度
3D 场景
两套美术
高特站：哑光灰地面 + 随机暗斑 + 线框铁塔；洙边站：霓虹网格地面。材质、光照、地平面完全不同。应统一为一套 preset（地面、雾、光照、辉光强度）。
图表配色
三套色族
收益柱用青→白渐变，充放电统计用蓝紫渐变，SOC 曲线用橙 + 青。蓝紫在整站色板里是外来色。应收敛为主色 + 2 中性 + 语义色。
透视穿帮
3D 透出面板
设备列表、详细信息页下方能看见 3D 场景的轮廓在动。数据页要么不渲染场景，要么容器改为不透明。
内部点位名外露
RackMaxVoltage
电芯健康页把寄存器点位名以 10px 青色等宽字直接印在卡片第三行。产品界面不应出现内部标识符。
坐标轴失控
SOC 轴 3 – 9
只有 1–2 个采样点时 ECharts 自动缩放，SOC=6 画出一条居中直线，看起来像坏了。应固定量程 + 显式"数据不足"态。
右侧竖条被裁切
数据面板
24px 宽的竖排把手在 1920 / 1366 / 390 下都出现文字截断（scrollWidth 525 vs clientWidth 24）。

八、落地路线

P0 · 止血（1–2 天）
  • 建立 :root 令牌层，把 24 个色值写成变量；先不改视觉，只替换引用
  • 字号收敛到 8 档整数，最小 11px；全站数字加 tabular-nums
  • 圆角统一 2 / 4 / 999 三档
  • 删掉 .tab 的 skewX、四角括号、标题渐变裁字、scanline
  • 标签-数值改固定两列栅格，禁止整行 space-between
  • 数据页容器改不透明，或数据页不挂载 3D
  • 电芯健康页去掉 RackVoltage 等点位名，补空态文案
P1 · 结构（3–5 天）
  • 12 列栅格 + 4px 间距体系，分区容器统一为"单层 + 表头底色"
  • 每页用 grid-template-rows 做满高分配，消灭底部死区
  • KPI 合并为分隔线式指标条，加入 24h sparkline
  • 四态状态语言（色 + 图标 + 文字）全站替换
  • ECharts 统一主题对象：固定量程、整数刻度、主色族、空数据态
  • 断点重做为 3 档：≤900 / ≤1280 / ≥1600，去掉重复规则
  • 顶栏改可换行 + 溢出收纳进"更多"，62px 改 min-height
P2 · 质感（1 周）
  • 两套 3D 场景合并为同一美术 preset，统一地平面/雾/辉光
  • 白天主题从"291 条覆盖"改为令牌双值，随 :root 一起切换
  • 动效三级 120/180/240ms + 统一缓动，数值过渡用补间
  • 电芯热力条：间隙、图例、阈值线、越限计数
  • 空态 / 加载 / 断连三态统一插画与文案规范
  • 暗光控制室与日光挂墙两种可读性场景各做一次校验
测量方式：headless Edge 驱动线上站点，逐页采集 getComputedStyle 与渲染像素；色板/圆角/字号/字距统计来自 css/style.css（92,333 字节 / 925 条规则）全量解析。 本页所有"目标"样式即为建议落地后的实际渲染效果，可直接作为规范参考。
