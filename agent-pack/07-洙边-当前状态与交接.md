## 2. 洙边 3D 场景现状（2026-10-28）

### 2.1 九条电线（走线 + 亮灯条件）

约定：`dir=1` 表示从 `pts[0]` 流向 `pts[最后一点]`；`loadEff = max(0, pv + st − meter)`；
`meter = −grid_kw`（正=卖电）；`pvOn = pv > .5`、`chg = st < −.5`、`dis = st > .5`。

| kind | 线（走线） | 亮灯条件 | 颜色 | 方向 |
|---|---|---|---|---|
| `pv` | 屋面组串 → 线槽 → 西墙直落 → 二楼分岔点(3.9m) | `pvSeen && pvOn` | 黄 | 下 |
| `pvlow` | 二楼分岔点 → 低位节点(1.2m) | `pvOn && (chg \|\| surplus>.3)` | 黄 | 下 |
| `pvh` | 二楼分岔点 → 沿西墙往南 → 西南角转弯 → 南墙二楼黑盒 | `pvOn && loadEff>.3` | 黄 | 进楼 |
| `sto` | 低位节点 → 低空横穿 → 柜**东面**接线盒 | `pvOn && chg`（**只有光伏充电才亮；储能放电/待机不亮**） | 黄 | 进柜 |
| `gsto` | 终端箱 → 柜前北车道(z3.15) → 折北 → 柜**西面**接线盒 | `chg && surplus<−.3`（电网在买电且在充） | 蓝 | 进柜 |
| `grid` | 低位节点 → 贴墙根向南 → 向西并入走廊(z3.60) → 终端箱 | `surplus>.3 && pvOn`（**只有光伏卖电才亮**） | 黄 | 上行 |
| `tower` | 终端箱 ↔ 拉线上塔中央 | 卖=`surplus>.3 && pvOn`（黄上行）；受电=`surplus<−.3`（蓝下行） | 黄/蓝 | 双向 |
| `stoh` | 柜**正面(南面)** → 楼前走廊(z2.95) → 南墙墙脚黑盒 | `dis && loadEff>.3` | 青绿 | 进楼 |
| `gl` | 终端箱 → 前院南沿(z5.45) → 折北 → 南墙进线盒 | `surplus<−.3 && loadEff>.3` | 蓝 | 进楼 |

**现场口径（2026-10-27/28 定稿）**：
- **储能设备不卖电、只给卫生院供电**；卖电只有光伏（储能放电再多、表在送电也不画卖电，表读数只在塔浮标写"送出 x kW"）。
- 柜子三面接线：**光伏进东面 / 国网进西面 / 储能出正面（南面）**，三面都有接线盒，线端收进盒里。
- 卫生院三路进线全在南墙西端（二楼光伏 / 墙脚储能 / 墙脚偏东国网），分层排开。
- 墙根不做黑盒：低位节点(1.2m) + 接线端子小球。

### 2.2 六工况（组合判定）

当前工况 = 下面成立项的组合，储能柜浮标显示"工况 x+x"（明细卡写全称）：

| # | 工况 | 判据 |
|---|---|---|
| 1 | 光伏→储能 | `pvOn && chg` |
| 2 | 光伏→卫生院 | `pvOn && loadEff>.3` |
| 3 | 光伏卖电上网 | `pvOn && surplus>.3` |
| 4 | 电网→卫生院 | `surplus<−.3 && loadEff>.3` |
| 5 | 电网→储能 | `chg && surplus<−.3` |
| 6 | 储能→卫生院 | `dis` |

典型组合：充电+供院=`1+2`；白天卖电=`1+2+3` 或 `2+3`；电网供电=`4`；电网充储能=`4+5`；储能供院+电网补=`4+6`。
**注意**：判定不满足时显示"全站待机"（如负载很小时不误报 4）。

### 2.3 光纹流速（与旭日东明同一口径）

- **全站一个流速**：`flowSpd = .25 + min(1, max(|st|, |surplus|)/100) × 1.6`（储能额定 100kW 为基准）；
  所有线共用（`flowSpeed()` 直接返回它）；`stepFlow` 位移系数 `.35`，与 `gaote-scene3d.js` 一致。
- 光纹间隔每 4.2 米一段；`on=false` 时 opacity .22、色 idle（0x24444a）。

### 2.4 其他要点

- **储能柜 SOC 光柱**（左右两侧）：高度按 SOC，**颜色跟随工况**（放电=青绿 / 光伏充=黄 / 电网充=蓝 / 待机=暗青），
  与柜体指示灯、柜底光晕同色（对齐旭日东明做法，亮色经泛光即"发光"）。
- **走线车道**：储能→卫生院 z2.95 / 国网→储能 z3.15 / 电网线 z3.60 / 电网直供 z5.45；
  贴地线线心 y .34，电缆墩 15 个按 x 每 2.5m 网格对齐、墩顶与线心齐平。
- **铁塔段**：光伏卖电黄上行、从电网受电蓝下行；**没有"储能卖电"的青绿段**。
- **`?nowires=1`**：URL 参数隐藏全部电线（电缆/光纹/塔上导线），用于截图对走向。

### 2.5 模拟工况对照页（`solar-demo.html` · 本地调试页，**已下线、不在线上**）

- 位置：项目根目录 `solar-demo.html`（**未部署**；部署清单 `tools/deploy-site.js` 的 INCLUDE 里没有它）。
- 用法：本地 `python -m http.server 8080` 后打开 `http://localhost:8080/solar-demo.html`。
- 12 个预设：`1 / 2 / 3 / 4 / 5 / 6`、`1+2`、`1+2+3`、`2+3`、`4+5`、`4+6`、`待机`；点一下 3D 立刻按该组数据跑。
- 三个滑杆（光伏出力 / 储能功率 ±、正=放负=充 / 卫生院负载）；**关口表自动算**：`grid_kw = load − pv − st`（正=取电）。
- 面板实时显示判出的"工况 x+x"和关口取/送电；脚本按"时间戳"加载，**不吃浏览器缓存**（改 js 刷新即生效）。
- 纯工况预设要点：1 = 光伏 25/充25/负载 0.1；3 = 光伏 60/负载 0.1；5 = 电网充 20/负载 0.1——避免"多出的电"误触发卖电。

## 3. 数据链路

- 光伏（阳光云）：`GET /solar/summary`（`power` 单位 **W**）→ `tools/solar-service.js`（8096）→ nginx `/solar/*` → `js/solar.js` → `setPower(power/1000, 110.16, 今日度)`。
- 储能（日升云）：`GET /risen/full`（`realtime.power_kw` 正=放 / 负=充；`grid_kw` 正=取电 / 负=送电；`load_kw`；`soc`）→ `tools/risen-cloud-service.js`（8097）→ `/risen/*` → `setStorage(...)`。
- 服务器上直接取数据（本机 curl，免 nginx 认证）：
  `curl -s http://127.0.0.1:8096/solar/summary`、`curl -s http://127.0.0.1:8097/risen/full`。
- 远程执行脚本：`node tools/remote-run.js "<命令>"`（SSH 免交互，凭据在脚本内，别把密码复制进新文件）。
